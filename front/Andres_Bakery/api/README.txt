# API (propuesta)

Podemos integrar una API para traer ingredientes e imágenes de repostería.
Opciones sugeridas:

- **Spoonacular**: recetas e ingredientes, requiere API key.
- **Edamam**: recetas con datos nutricionales, requiere API key.
- **TheMealDB**: catálogo simple, ideal para prototipos.
- **Unsplash/Pexels**: imágenes de repostería, requiere API key.

Cuando definamos la opción, reemplazamos el contenido mock por datos reales.
