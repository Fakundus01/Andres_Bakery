# Andres_Bakery

Pág web de cocina con estilo pastel inspirado en Stardew Valley.

## Instalación (Vite + React)

> Nota: la instalación de dependencias requiere acceso a npm.

```bash
npm install
npm run dev
```

## Backend (Flask)

El backend vive en la carpeta `backend` y expone APIs para autenticación, productos, órdenes, contacto por correo y pagos con tarjeta. Revisa `backend/README.md` para la configuración completa.
